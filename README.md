# Taipei Together

A public, static four-day guide for nine friends visiting Taipei in October 2026. Open `index.html` in a browser or publish the repository with GitHub Pages.

The trip's private accommodation address, flight identifiers and exact flight times are deliberately excluded. The base marker represents Guting Station, a public area marker. Suggestions and forecasts can change; confirm directly with linked venues before booking.

The map uses MapLibre and OpenFreeMap. Forecasts use Open-Meteo. Photos are credited in [PHOTO-CREDITS.md](PHOTO-CREDITS.md).
